# Freipen ✒️ 端到端加密写作空间（多工作区，可在线部署）

---



> **Obsidian 风格** 的所见即所得（WYSIWYG）Markdown 写作应用，**支持多个独立工作区**。
> 每个工作区各自使用独立主密钥，**端到端加密**：文件结构、文件夹名、文件名、每篇笔记、
> 每个附件，全部以 AES-256-GCM 密文保存；前端与后端之间**只传输密文**，主密钥只存在于
> 你的浏览器内存中。默认跑在本地 `127.0.0.1`，也可以作为**在线应用**部署到局域网/服务器
> （`FW_HOST=0.0.0.0` + HTTPS 反向代理），内容同样只有你能解开。

## ✨ 功能特性

**Obsidian 式写作体验**
- 左侧文件树：文件夹 + 笔记 + 附件、实时搜索过滤、行内重命名、悬停快捷按钮
- **可折叠侧边栏（rail 模式）**：折叠后顶部品牌行整体隐藏（不再错位），只留图标栏；
  顶栏/底栏变成悬浮层完全透明，鼠标贴近窗口上/下边缘才滑出显示
- **独立设置页**（侧边栏 ⚙️）：外观与主题、日记（开关/文件夹/模板）、默认编辑模式；
  所有控件均为自绘样式（不使用原生下拉框）
- **多种主题样式**：石墨深色（默认）、明亮浅色、午夜蓝、暖纸，一键切换并记忆
- 顶栏**编辑模式切换**：即时渲染（所见即所得）⇄ Markdown 源码（`Ctrl+E`），双向可编辑
- **选中文字后浮出编辑工具栏**：加粗 / 斜体 / 删除线 / 行内代码 / H1–H3 / 引用 / 链接
- **情境化右键菜单**：表格上右键可“在上/下方插入行、左/右侧插入列、删除行列、删除整表”
  （表头行已保护：禁止在表头上方插行或删除表头行，避免生成非法重复表头）；
  图片上右键可缩放预览 / 删除；附件上右键可缩放预览 / 插入引用 / 下载 / 移除；文本区右键插入表格、列表、待办等
- 所见即所得 Markdown 编辑（Milkdown / ProseMirror），输入语法即时渲染

**日记功能（Obsidian Daily Notes）**
- 侧边栏 📅 按钮：**左键直接打开/创建今日日记**，**右键打开日历视图**
- 可配置**日记存放文件夹**（默认自动创建“日记”文件夹）与**日记模板**
  （支持 `{{date}} {{year}} {{month}} {{day}} {{weekday}} {{time}} {{iso}}` 变量）
- 每篇日记名称形如 `2026-09-04`；**日历视图**按月展示，今天高亮、有日记的日期带绿点，
  点击任意日期即可打开（不存在则按模板自动创建）

**每篇文章独立的“附件目录”**
- 粘贴 / 拖入图片或文件 → 自动作为该篇笔记的附件上传（密文存储）
- 笔记行可**展开附件目录**，或右键 → “附件列表 (N)” 查看/添加/预览/下载/移除
- 附件行带**“已引用”标记**：正文中引用过的附件实时标注；状态栏显示“附件 N（M 已引用）”
- 图片**缩放预览**：放大 / 缩小 / 100% / 适应窗口；图片以 `attachment://<id>` 引用存储
- 打开时自动解密显示，保存时只回传密文引用

**仿 Obsidian 的文件管理**
- **拖拽移动**：用鼠标把笔记/文件夹拖入目标文件夹（重名自动加序号）
- **右键菜单**：新建、重命名、删除、**复制 / 剪切 / 粘贴**（复制会深拷贝正文与附件并重写引用）
- 键盘快捷键：新建、立即保存、模式切换、锁定、F2 重命名

**多工作区与全工作区加密**
- **多工作区**：门禁页可创建/切换多个工作区，各自独立主密钥、互相不可见
- PBKDF2-HMAC-SHA256（600,000 次迭代，随机盐）派生 **AES-256-GCM** 密钥
- 密钥为 **non-extractable** CryptoKey，只活在浏览器内存里，服务端与磁盘上都没有密钥材料
- 目录树、笔记正文、附件正文都单独随机 IV 加密并带用途绑定的认证数据（AAD）
- 默认仅监听 `127.0.0.1`；部署在线应用时可开放 `FW_HOST=0.0.0.0`（建议配 HTTPS）
- 严格 CSP、运行时零第三方网络请求；错误密钥经 GCM 认证直接拒绝

## 🔒 安全模型

```
浏览器（明文只出现在这里）
   │  PBKDF2(主密钥, 随机盐) → AES-256-GCM 密钥（不可导出，仅内存）
   │
   ▼  只发送 Base64 密文（目录树 / 笔记正文 / 附件字节）
Node 服务（默认 127.0.0.1:4100，可 FW_HOST 开放为在线服务）
   │
   ▼  仅落盘密文
data/workspaces.json            ← 工作区注册表（id/名称/创建时间，仅门禁页元信息）
data/workspaces/<id>/vault.json ← 加密的目录树（文件夹 / 笔记名 / 附件元数据）
data/workspaces/<id>/notes/*.json ← 笔记正文与附件字节的密文（uuid 无语义）
```

- 服务端不理解正文与文件结构：连文件夹与文件名字、附件文件名都只存在于加密的目录树里。
  （工作区名称作为注册表元信息，用于登录页区分多个工作区，不含任何内容。）
- **备份** = 复制整个 `data/` 目录；恢复 = 放回原位置并用对应主密钥解锁。
- 主密钥绝不外传、绝不被保存；忘记主密钥 = 该工作区数据永久无法恢复。

## 🚀 快速开始

**环境要求**：Node.js ≥ 20（服务端零第三方运行时依赖；前端构建产物已随项目放在 `dist/`）

- **Windows**：双击 **`start.bat`**，浏览器打开 `http://localhost:4100`
- **命令行**：`npm start` 或 `node server.js`，然后访问 `http://localhost:4100`
- 若 `dist/` 缺失：先 `npm install` 再 `npm run build`
- **首次使用**：设置主密钥（≥6 位，建议更长）→ 自动生成欢迎笔记，即可开始写作；
  之后可在门禁页「＋ 新建」继续创建独立工作区
- **部署为在线应用**：`FW_HOST=0.0.0.0 node server.js`（配合 Nginx/Caddy 等 HTTPS 反向代理与鉴权）

| 打开设置 | `Ctrl/Cmd + ,` |
| 新建笔记 | `Ctrl/Cmd + N` |

| 插入图片/文件 | 直接**粘贴**或**拖入**编辑器 |

## ⚙️ 配置（环境变量）

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `FW_PORT` | `4100` | 监听端口 |
| `FW_HOST` | `127.0.0.1` | 监听地址。保持默认即仅本机可访问；**在线部署**时设为 `0.0.0.0` |
| `FW_DATA` | `项目/data` | 密文数据目录（内含多工作区注册表与各工作区密文） |

## ⚠️ 注意事项

- 主密钥一旦忘记**无法找回**；建议定期备份 `data/` 目录到安全位置。
- 应用**不提供“重置工作区”功能**（避免误操作销毁数据）；如需彻底清空某工作区，
  可在门禁页右键/删除或自行删除 `data/workspaces/<id>/` 后重启服务。
- 本地使用请保持 `FW_HOST=127.0.0.1`；**在线部署**时务必置于 HTTPS 反向代理之后，
  并为你的场景补充访问鉴权（如 Basic Auth / 单点登录），本应用本身不含账号系统。
